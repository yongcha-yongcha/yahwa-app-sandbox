# 야화 앱 시연판 (PM 실험용)

실제 야화 앱 화면을 **목업 데이터만으로** 돌려 보는 저장소예요.
AI(Claude Code, Cursor 등)로 화면·문구·콘텐츠를 마음껏 바꿔 보고, 좋은 아이디어를 서로 공유하는 용도예요.

> **운영 서버와 완전히 끊겨 있어요.** 이 저장소에는 운영 DB 주소·키가 없고, 서버 코드도 없어요.
> 댓글·좋아요·편지·결제는 모두 **내 브라우저 안에서만** 처리되고, 다른 사람이나 운영 DB에는 아무것도 남지 않아요.

## 1. 받기

- GitHub 페이지 오른쪽 위 초록색 **Code → Download ZIP** → 압축 풀기
- (git을 쓴다면) `git clone` 해도 돼요

## 2. 처음 한 번 준비

[Node.js](https://nodejs.org) LTS(20 이상)를 설치한 뒤, 압축을 푼 폴더에서 터미널을 열고:

```bash
npx pnpm@10 install
```

## 3. 실행

```bash
npx pnpm@10 start
```

터미널에 `Waiting on http://localhost:8081` 이 보이면 브라우저(크롬 권장)에서 **http://localhost:8081** 을 열어요.
처음 열 때는 화면을 만드는 데 30초~1분쯤 걸려요.

- PC 화면이 넓으면(1000px 이상) **가운데에 앱 화면, 오른쪽에 시연도구**가 보여요.
- 창이 좁으면 오른쪽 아래 **시연도구** 버튼으로 열어요.

## 4. 시연도구로 할 수 있는 것

| 묶음 | 하는 일 |
|-|-|
| 화면 이동 | 인연 홈 · 마음함 · 편지함 · 커뮤니티 · MY와 그 안의 화면을 바로 열어요. 웰컴·로그아웃·새 회원 가입 흐름도 볼 수 있어요. |
| 오늘의 밸런스 | 밸런스 카드로 바로 가기, 다시 하기(오늘 고른 답 지우기), 제목(T1 · T2) · 표지 캐릭터(7 · 8 · 9) · 뒷면(피크닉 · 밤하늘 모빌 · 오락기) 바꾸기 |
| 내 계정 | 로그인/로그아웃, 내 성별(남·여), 리프·포인트 개수, 시간 하루씩 넘기기 |
| 상황 만들기 | 편지 받기, 상대가 답장하기, 마음 받기, 내 글에 댓글 받기, 쿠폰 받기 같은 상황을 한 번에 만들어요 |
| 요청 기록 | 앱이 보낸 요청을 목업이 대신 받은 기록이에요. '운영 서버로 나간 요청 0건'을 확인할 수 있어요 |
| 처음 상태로 되돌리기 | 내가 쓴 글·편지·좋아요를 지우고 처음 목업 데이터로 돌아가요 |

## 오늘의 밸런스 (11-28 시안)

인연 홈 카드 줄의 **맨 앞 칸**이에요. 첫 화면에는 1번 인연이 보이고, **왼쪽으로 넘겨야** 밸런스 카드가 나와요.

1. 앱을 열면 늘 표지부터 보여요(기본: T1 깔끔 굵게 · 7 정면 · 피크닉). 표지(하트 캐릭터)에서 **[열어보기]**를 누르면 카드가 뒤집히며 오늘의 질문이 나와요.
2. 뒷면에서 마음에 드는 카드를 **바로 눌러** 골라요(따로 고르기 버튼 없음). 고른 비율이 나와요.
3. 같은 쪽을 고른 한 사람이 **1번 칸**(밸런스 바로 다음)에 생기고, '같은 쪽 사람을 찾았어요'가 잠깐 보인 뒤 그 카드로 넘어가요. 카드 위에 **'같이 부먹파'** 칩이 붙어요.
   밸런스 카드는 참여한 뒤에도 결과 면 그대로 남고, 아래에 **'내일 12시, 새 질문으로 또 만나요'**가 보여요.
4. 오늘 밸런스에 참여한 사람은 **홈 카드에도** 고른 답 칩이 붙어요(내 답과 같으면 '같이 부먹파', 다르면 '찍먹파').
5. 참여한 사람의 **프로필**에는 그 사람이 고른 답이 **'전 부먹파예요'** 칩으로 보여요(내 답과 달라도 보여요).
   시연판의 다른 회원들은 85%가 참여하고 답은 반반으로 정해져 있어요(날마다 바뀜).

하루(정오~정오)에 한 번만 고를 수 있어요. 다시 해 보려면 시연도구의 **오늘의 밸런스 → 다시 하기**를 눌러요.
시연판은 사람이 적어서, 같은 쪽 사람은 아직 공개 전인 오늘의 인연 중에서 앞당겨 소개해요.

## 5. AI로 바꿔 보기 — 어디를 고치면 되나요?

| 바꾸고 싶은 것 | 파일 |
|-|-|
| 사람(닉네임·나이·지역·사진) | `src/demo/people.ts` |
| 프로필 소개·답변·태그 | `src/demo/seed/users.ts` |
| 편지 내용 | `src/demo/seed/letters.ts` |
| 커뮤니티 글·댓글·알림 | `src/demo/seed/community.ts` |
| 매장·쿠폰·리프 내역 | `src/demo/seed/my.ts` |
| 시연도구의 상황 버튼 | `src/demo/rpc/*.ts` 의 `scenarios` |
| 오늘의 밸런스 질문 · 답 · 칩 문구 | `src/components/affinity/balance/content.ts` |
| 오늘의 밸런스 카드 모양(표지 · 뒷면) | `src/components/affinity/balance/BalanceCard.tsx`, `styles.ts` |
| 화면 자체(디자인·문구) | `src/screens/*`, `src/components/*` |
| 사진 | `public/demo/` 에 넣고 `/demo/파일이름.jpg` 로 써요 |

시드(목업 데이터) 파일을 고치면 브라우저를 새로고침했을 때 자동으로 새 데이터로 시작해요.

AI에게는 이렇게 부탁하면 돼요:

> 커뮤니티에 '퇴근길 한 줄' 카테고리를 만들고, 그 카테고리에 글 5개를 목업 데이터로 넣어 줘.

## 6. 서로 공유하기

- 바꾼 화면을 캡처하거나 화면 녹화해서 공유하거나,
- 바꾼 폴더를 ZIP으로 묶어 전달하거나,
- GitHub를 쓴다면 이 저장소를 Fork해서 올려도 돼요.

## 지켜 주세요

- 이 저장소에 **실제 서버 주소·키(.env)를 넣지 마세요.** 시연판은 목업 데이터만으로 돌아가요.
- 사진은 모두 AI로 만든 가상 인물이에요. 실제 사람 사진은 넣지 말아 주세요.
- 지도는 키가 없어 비어 보일 수 있어요. 결제는 실제 결제창 없이 '성공'으로 처리돼요.
